## 🎯 Project Overview

This project replicates core Google Drive functionality, providing users with a secure, scalable platform for:

- 📁 **File Storage & Management** - Upload, organize, and manage files in the cloud
- 👥 **User Authentication** - Secure login and registration system
- 🔗 **File Sharing** - Share files and folders with other users
- 📂 **Folder Hierarchy** - Organize files in nested folder structures
- 🔍 **Search & Filter** - Quick file and folder search capabilities
- 🗑️ **Trash System** - Soft delete with restore functionality

---

## ✨ Features

### Core Functionality

| Feature | Description |
|---------|-------------|
| 📤 **File Upload/Download** | Upload multiple file types and download them securely |
| 📂 **Folder Management** | Create, rename, move, and delete folders |
| 🔒 **Access Control** | Public/private file sharing with permission levels |
| 👤 **User Management** | User registration, login, and profile management |
| 📊 **Storage Quota** | Track and manage storage usage per user |
| 🕒 **Version History** | Track file modifications and changes |
| 🔍 **Advanced Search** | Search by filename, type, date, and owner |
| 🗂️ **File Organization** | Drag-and-drop interface for file organization |

### Security Features

- 🔐 **Secure Authentication** - Password hashing and session management
- 🛡️ **File Encryption** - Secure file storage and transmission
- 🚫 **Access Control Lists (ACL)** - Fine-grained permission management
- 📝 **Activity Logging** - Track user actions and file access
